# Product Context

## Product Overview
- Sản phẩm chính: Đồ handmade (trang sức, phụ kiện, quà tặng thủ công, decor...).
- Đối tượng khách hàng: Người yêu thích sản phẩm thủ công, quà tặng cá nhân hóa.
- Giá trị nổi bật: Sản phẩm độc đáo, thủ công, có thể đặt làm theo yêu cầu.

## User Flows
- Tìm kiếm sản phẩm → Xem chi tiết → Thêm vào giỏ hàng → Đăng nhập/Đăng ký → Thanh toán → Theo dõi đơn hàng.
- Duyệt danh mục → So sánh sản phẩm → Thêm vào wishlist.
- Đọc blog → Tìm hiểu về sản phẩm, hướng dẫn sử dụng.
- Đặt hàng custom (theo yêu cầu) → Nhận báo giá → Thanh toán.

## Future Enhancements
- Tích hợp AI chat hỗ trợ khách hàng 24/7.
- Hệ thống khuyến mãi, mã giảm giá cá nhân hóa.
- Đánh giá, bình luận sản phẩm.
- Giao diện mobile app hoặc PWA.
- Tích hợp thanh toán đa dạng (Momo, ZaloPay, Stripe...).
- Theo dõi đơn hàng real-time, thông báo trạng thái đơn hàng.
